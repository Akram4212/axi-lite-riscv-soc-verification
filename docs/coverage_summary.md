## AXI-Lite Functional Coverage

The current AXI-Lite subsystem functional coverage is:

```text
96%
```

This coverage includes AXI-Lite transaction behavior, peripheral register
accesses, byte strobes, error responses, and address-decoding scenarios.

## Full-SoC Firmware Coverage

Merged Verilator coverage was collected across five firmware workloads:

- `start`
- `memory_test`
- `branch_test`
- `gpio_test`
- `timer_test`

Each workload was assembled and linked using the RISC-V cross-toolchain,
converted into a Verilog memory image, loaded into AXI-Lite RAM, and executed
by the five-stage RV32I core.

### Merged Integration Coverage

| Metric | Covered | Total | Rate |
|---|---:|---:|---:|
| Lines | 1,533 | 1,770 | 86.6% |
| Branches | 3,528 | 5,165 | 68.3% |

The merged report includes RTL, SystemVerilog interface headers, and the
simulation wrapper. A separate RTL-only report is generated by excluding
`include/` and `tb/`.

The full-SoC firmware coverage complements the more exhaustive block-level
verification. For example, the decoder and processor-core unit tests exercise
instruction behaviors that are not all represented in the integration
firmware workloads.

### Reproducing the Report

Run:

```bash
make coverage_soc
```

The generated reports are located at:

```text
coverage_soc/html/index.html
coverage_soc/rtl_html/index.html
```

The first report includes the complete simulated hierarchy. The second report
contains only synthesizable RTL.
